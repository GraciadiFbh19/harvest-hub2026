# Harvest Hub 2026

Project by GraciadiFbh19.

Harvest Hub is a web application that helps farmers and sellers from Nana Bosoma Market to sell and offer all agricultural products online.

## What it does
Harvest Hub connects farmers/sellers directly with buyers, without middlemen.

It helps to:
- Reduce dependence on middlemen 
- Allow sellers to earn fairly, without giving any percentage to anyone
- Make agricultural products more accessible to buyers

## User Interfaces
- Farmer: Publish products, manage stock and sales
- Buyer: Browse products, order easily
- Delivery: Manage deliveries from sellers to buyers

## Project Structure
- `harvestHub` - Main frontend
- `harvesthub-backend` - Backend
- `harvesthub_admin` - Admin dashboard
